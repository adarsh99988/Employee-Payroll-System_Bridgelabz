# 📊 Employee Payroll System (EPS)

A server-side web application built using **Node.js, Express, and EJS** to manage employee records and calculate monthly payroll.

---

## 🎯 Objective
The goal of this project is to create a payroll management system where users can:
- Add employees
- Edit employee details
- Delete employees
- Calculate tax and net salary automatically
- Store data in a JSON file

---

## 🛠️ Technologies Used
- Node.js  
- Express.js  
- EJS Template Engine  
- CSS  
- File System (fs.promises)
